# الموقع الإلكتروني (Website)

## 📄 الصفحات المتاحة

### 1. الصفحة الرئيسية (HomePage)
**المسار:** `/`

**المحتوى:**
- شريط التنقل العلوي
- قسم البطل (Hero Section) - عرض جذاب
- قسم الخدمات - 4 خدمات رئيسية
- معرض الأعمال - صور قبل وبعد
- نموذج الحجز السريع
- تقييمات العملاء
- معلومات التواصل
- خريطة الموقع
- تذييل الصفحة

### 2. صفحة الخدمات (ServicesPage)
**المسار:** `/services`

**المحتوى:**
- عرض جميع الخدمات بالتفصيل
- أسعار ومدة الخدمة
- تفاصيل الخدمات الفردية
- عروض خاصة وباقات
- صور توضيحية
- زر الحجز لكل خدمة

### 3. صفحة أعمالنا (GalleryPage)
**المسار:** `/gallery`

**المحتوى:**
- معرض شامل للأعمال
- تصفية حسب نوع الخدمة
- تقييمات العملاء لكل عمل
- قسم "قبل وبعد" للعروض المرئية
- صور عالية الجودة
- نموذج العرض السريع

### 4. صفحة التواصل (ContactPage)
**المسار:** `/contact`

**المحتوى:**
- معلومات التواصل الكاملة
- نموذج الرسالة
- خريطة الموقع التفاعلية
- ساعات العمل
- الأسئلة الشائعة (FAQ)
- روابط وسائل التواصل الاجتماعي

### 5. صفحة المتجر (ShopPage)
**المسار:** `/shop`

**المحتوى:**
- عرض المنتجات
- تصفية حسب الفئة
- البحث عن المنتجات
- عرض السعر والتقييم
- سلة الشراء (Shopping Cart)
- معلومات المخزون
- زر الشراء

## 🎨 المميزات التصميمية

✨ **التصميم المتجاوب (Responsive)**
- يعمل على جميع أحجام الشاشات
- تجربة مستخدم سلسة على الجوال والويب

✨ **الألوان والتدرجات**
- تدرجات فاخرة (Purple → Pink → Amber)
- ألوان متناسقة وجذابة
- تصميم حديث وجميل

✨ **سهولة التنقل**
- شريط تنقل ثابت في الأعلى
- روابط سريعة للأقسام
- قوائم منسدلة على الجوال

✨ **تفاعل المستخدم**
- تأثيرات عند تمرير الفأرة (Hover Effects)
- نماذج تفاعلية
- عرض ديناميكي للبيانات
- تصفية وبحث فوري

## 📦 المكونات (Components)

### PublicNavbar
- شريط تنقل للصفحات العامة
- شعار الصالون
- روابط التنقل
- زر الحجز
- قائمة الجوال

## 🚀 لتشغيل الموقع

```bash
cd frontend
npm install
npm run dev
```

الموقع سيعمل على: **http://localhost:3000**
